# 🚀 Desafio Trilha Front-End

Este projeto consiste no desenvolvimento de uma página de apresentação pessoal e portfólio dinâmico, desenvolvido como projeto prático no **Programa Trilhas** (Trilha de Front-End).
Foi criado com **HTML5**, **CSS3** e ícones interativos, garantindo uma navegação simples, organização visual e responsividade para apresentar informações pessoais, trajetória académica, projetos e certificados de conclusão[cite: 1, 2, 3, 4].

## 🚀 Funcionalidades

- **Página Principal (`main.html`):** Apresentação com foto de perfil, nome, título descritivo e hiperligações para redes sociais (GitHub e LinkedIn)[cite: 1, 4].
- **Navegação Modular:** Botões interativos que direcionam para as secções internas do site.
- **Secção Sobre Mim (`auth.html`):** Descrição detalhada da trajetória académica e profissional, destacando a união entre a área jurídica e a tecnologia[cite: 1, 2, 3].
- **Exibição de Certificados (`certificates.html`):** Galeria dedicada à apresentação visual de diplomas e certificados (Ensino Médio e Curso Técnico).
- **Apresentação de Projetos (`projects.html`):** Estrutura destinada à listagem e exibição dos projetos desenvolvidos.
- **Layout Responsivo:** Estilização desenvolvida em CSS para garantir uma boa usabilidade e adaptação em diferentes ecrãs[cite: 1, 4].

---

## 🧩 Tecnologias Utilizadas

- **HTML5** (Estruturação semântica das páginas)
- **CSS3** (Estilização personalizada e esquemas de cores)
- **Ionicons** (Biblioteca de ícones vetoriais para redes sociais)
- **Git & GitHub** (Controlo de versões e hospedagem de código)
